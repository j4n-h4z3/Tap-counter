# Tap Counter – Homepage

Support- und Datenschutz-Seite für die iOS-App **Tap Counter**.

Diese Website wird über GitHub Pages gehostet und dient als offizielle Support-Seite für die App im Apple App Store.

## Inhalt

- `index.html` – Support-Seite mit App-Beschreibung, Features und FAQ
- `privacy.html` – Datenschutzerklärung (Deutsch/Englisch)
- `favicon.svg` – Favicon
- `og-image.png` – Social-Media-Vorschaubild
